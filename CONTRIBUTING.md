Thanks for your interest in contributing!

Guidelines
----------

- Fork the repository and create a feature branch.
- Keep changes small and focused; open issues for larger work.
- Run the test suite before submitting: `pytest backend/tests/`.
- Follow existing code style; keep functions small and documented.

Pull Request
------------

- Open a PR against `main` with a clear description of your changes.
- Include tests for new behavior and update documentation when needed.
- Add screenshots or a short GIF for UI changes.

Code of Conduct
---------------

Be respectful and collaborative. Report abusive behavior to the repo owner.
